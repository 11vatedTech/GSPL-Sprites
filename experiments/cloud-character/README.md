# Cloud Character Production Test — Mosslight Warden

This experiment tests whether 11vatedTech can generate, validate, package, and preview a detailed animated 3D game character using GitHub-hosted compute only.

## Deliverable

A high-detail fantasy-adventure character with a rigged GLB export, real animation clips, an interactive browser controller, visual evidence, and machine-readable verification results.

The character recipe is authored for this experiment. Geometry, anatomy, skinning, clothing, hair, props, textures, and animation data are generated by Ara 3D Gen from its MakeHuman-derived CC0 asset library. This is not a primitive-shape character. The upstream mesh is not misrepresented as original 11vatedTech topology. Our contribution is the character recipe, production orchestration, browser runtime, validation, packaging, and later GSPL integration.

## Art direction

Mosslight Warden is a forest-guardian / fantasy-adventure fighter. The recipe uses a high-detail body, cornrow hairstyle, determined expression, woven tunic, patterned wrap, sash, amulet bandolier, arm guards, sandals, and sword. The palette is indigo, forest green, crimson, and warm gold.

## Cloud build

GitHub Actions checks out this repository and a pinned Ara 3D Gen commit, installs dependencies in the hosted runner, downloads the documented CC0 character data, builds the asset catalog, exports the high-detail character, runs the upstream GLB/animation regression suite, builds the browser viewer, and tests the actual generated GLB in headless Chromium. The GLB, viewer, screenshot, and verification report are uploaded as a workflow artifact.

No local Blender, Unreal, Godot, GPU, or user API key is required. Generation is CPU-based; the viewer uses browser WebGL.

## Acceptance gates

- Non-empty GLB export.
- At least one skinned mesh and a real skeleton.
- At least 30,000 triangles.
- At least 10 named animation clips.
- Idle, walk, run, and sword/combat clips are discoverable.
- Browser viewer loads the exact generated GLB without runtime errors.
- Keyboard movement changes the character root position.
- Screenshot, JSON report, and source/license manifest accompany the package.

A green workflow proves technical gates only. It does not certify the final aesthetic standard; human visual review remains explicit.

## Relationship to GSPL Sprites

This experiment does not replace the GSPL compiler. The next integration gate is to ingest the verified GLB into GSPL's governed asset graph, preserve source hash and rights metadata, and connect the asset to the existing 3D projection and animation contracts. That integration is not claimed as complete here.
